## 开发与更新

已修复官方高清图片加载时的 `wx[method] is not a function`：此前误用了小游戏的 `wx.loadSubpackage`，现在普通小程序通过 `require.async` 加载图片分包的资源入口。分包下载失败后可重试；并发请求共用一次下载。已在微信模拟器确认首关高清图成功显示；资源测试覆盖24张高清图和失败重试。

已修复微信v2默认按钮的184px宽度覆盖布局导致列表变窄、文字竖排的问题；浏览器验收加入对应默认样式。画布改用当前页面的 `createSelectorQuery()`，解决开发者工具 API hook 环境下全局查询丢失页面作用域、棋盘持续加载的问题。拼片图集显示尺寸与像素尺寸同步，并等待视图更新后导出，解决微信导出放大裁切的问题。

图片分包下载、画布准备、图片读取和图片导出均有超时与重试，避免无限加载。回归覆盖三档图集导出、失败重试、退出后取消旧结果，以及页面绑定查询与超时释放。

已修复拖动拼片被棋盘遮住的问题：棋盘由隐藏Canvas绘制后在普通图片视图显示，拖动预览与棋盘共享页面显示层。棋盘使用两层图片缓冲，保留旧图直到新图触发加载完成事件再切换，避免放下拼片时图片解码造成短暂白屏。每次绘制使用独立图片键与请求序号，过时导出或离开页面后的加载事件不能覆盖当前画面。

新增故事和图像写入 `web/shared.js`、`web/assets`，运行 `python scripts/sync-miniprogram.py` 生成小程序资源，再运行 `python scripts/prepare-ios.py` 同步iOS内置网页。不要分别修改生成的 `miniprogram/shared.js`。

小程序逻辑检查：`npm run test:mini`。包校验：`python scripts/validate-miniprogram.py`、`python scripts/validate-project.py`。

浏览器检查：`npm test`。本机使用已安装Edge验证时，PowerShell先设置 `$env:PUZZLE_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'`。
