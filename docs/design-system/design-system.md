# 视觉与交互基础

> 2026-10-13 v0.4：iOS动态系统色；接入用户提供的六张故事插画、欢迎图和图标。玩法改为网格拖动、中性贴格、摆放时不判对错、提交后仅给整体结果，支持12/24/48块和不限次原图预览。图片由用户提供，本次没有调用生图API。

本系统适用于成人为主的 iOS 圣经拼图。用户提供的八张图已用于HTML交互原型；它不是原生App。

## 视觉方向

推荐“收藏画册”：低饱和iOS 系统背景色背景、系统标签色文字、成熟手绘场景、系统蓝主按钮。图片负责故事感，界面负责秩序。主视觉来自插画，UI 不持续漂浮、不加装饰粒子。首页只保留一个主要入口。

网页原型实现浅色与深色近似值并跟随系统主题；原生动态色与实机视觉需另做验收。正文以 4.5:1、大字和关键控件以 3:1 为最低对比目标。禁用、分隔线不可承担必要状态识别。图片内不用生成文字；图上的字必须由程序排版并放在高对比底板上。

## 字体与尺寸（iOS pt）

- 正文采用系统字体，中文跟随系统字体回退；不绑定网页西文字体作为中文方案。
- 首页标题 28 / semibold；页面标题 24 / semibold；小标题 20 / semibold；正文 17 / regular；按钮 17 / semibold；辅助信息 15；说明 13。
- 对应 Dynamic Type 的 title、title2、headline、body、subheadline、footnote 角色，使用语义样式，不固定缩小文字。
- 拼图进度使用等宽数字。故事正文行距约字号的 1.5～1.7 倍，按实际系统排版验证。
- 超大字体时选项换行、卡片拉高、列表改为单列；不截断人物名称和按钮标签。

## 间距与形状

间距取 4 / 8 / 12 / 16 / 20 / 24 / 32。iPhone 左右通常 20pt，小屏 16pt。圆角：按钮 12、封面 16、Sheet 24、棋盘容器 12。拼片由裁切形状决定，不套用按钮圆角。阴影仅用于拼片抓起和浮层，普通列表以留白区分。

## 原生布局

- Tab 仅出现在故事、我的故事集与收藏三个根页面；设置从右上角进入。
- 关卡列表与准备页由 NavigationStack 推入；拼图以全屏 presentation 打开，内部是一条稳定的 play/guess/reveal 流程。
- iPhone 以竖屏为主，尊重安全区，底部操作使用 safeAreaInset；不手写固定状态栏高度。
- 阅读页允许滚动；拼图棋盘和当前可用拼片尽量同时可见。小屏使用折叠工具区与独立滚动的多行托盘，而不是把触控面积缩小。
- iPad 如首版支持，棋盘左、托盘右；最大化利用空间而非机械放大 iPhone。

## 动效

点击反馈 100ms；拼片释放后自动贴合所在格子，所有格子行为相同；面板进入 240ms、退出 180ms；完成后的接缝淡出 280ms。动画只解释状态变化；没有连续闪动。Reduce Motion 下使用短淡入或立即切换，关闭位移、缩放和庆祝粒子。声音与触感独立设置，遵守系统静音策略。

## 无障碍

常用控件热区至少44×44pt。拼片支持拖动与方向键换格；放大片保证48块模式的可抓取尺寸。原生VoiceOver通过拿起、上下左右换格与放下完成同样的网格定位，不提供正确目标。网页已提供键盘微调，但不等于已通过原生无障碍验收。Sheet关闭后恢复焦点。所有摆放无对错反馈，只有提交后播报整体结果。

## 内容语言

成人语气：简洁、温和、具体。用“已完成拼图”“再观察一下画面中的线索”“收藏这个故事”，避免幼儿化称赞、羞辱性答错提示和强制连续签到。设置不展示未上线的功能开关。

原生实现优先使用动态语义色 `Color(.systemGroupedBackground)`、`Color(.secondarySystemGroupedBackground)`、`Color(.label)`、`Color(.secondaryLabel)` 和系统 tint，而非硬编码网页近似值。UI 系统色不改变插画颜色。网页浅/深色只是原型，需要原生实机复核。

当前预览规则：准备页与拼图页可一键打开完整原图，不二次确认、不限次数、无惩罚。原生支持放大查看；返回后棋盘格子、随机托盘顺序、托盘与棋盘滚动位置保持。姓名与故事文本仍由完成后的揭晓页面展示。

## 自建故事集 v0.4

沿用语义系统色、共享按钮、44pt热区和4:3封面。我的故事集是独立根入口；创建、故事集详情、图片编辑由此推入。官方内容与自建内容在入口区分；收藏包含两种内容。输入项使用带标签的原生表单，保存前校验，错误保留草稿。图片选取仅主动触发；数据保留当前浏览器，不进行网络上传。编辑页显式显示草稿/已保存/保存失败；图库读取期间显示加载而非空态。

裁切与完整保留都不拉伸原图。主体位置、缩放滑块只用于裁切，处理结果供预览和拼图共同使用；完整保留用中性背景补边。默认关闭认人物题目，配置时要求三个不重复选项及有效答案。替换图片或更改裁切生成新版本，旧进度与收藏引用原版本；试玩不污染通关或收藏。

## 最新网格规则

格子线按4×3、6×4、8×6显示，不标答案编号。所有格子均自动贴合，不读取正确答案；已放片互换，托盘新片放已占格则旧片退回托盘。托盘四列、至少四行视窗，全部碎片在其中上下滚动。准备页显示完整原图，不用环境局部裁切。

## iOS 容器实现 v0.5

SwiftUI承载WKWebView共享玩法；默认手机视图移除展示侧栏、模拟状态栏和边框，安全区由原生容器提供。界面通过原生UIColor语义色跟随系统。固定本机HTTP来源与持久WKWebsiteDataStore保存图片和进度；不访问外部服务器。选图通过系统PHPicker/文件选择器，声音和触感桥接原生API，不依据格子对错触发。桌面设计演示使用?prototype=1。最低iOS16；首版iPhone竖屏。
