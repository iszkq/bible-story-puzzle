# 组件地图

暂停、提交校验、重开与新局确认、内容/存档说明、删除确认统一复用 iOS 底部面板。暂停提供继续拼图、返回故事库、重新开始；错误提交保留摆放并可直接查看原图。详情收藏入口置于导航栏，图像先于人物标题；官方揭晓顺序沿用 iOS 的“你发现了”、人物、故事标题、完整图片、正文、出处、收藏、下一故事、返回故事库。自建草稿表单保持标题、说明与操作顺序一致，仅系统选图器和微信导航安全区使用平台组件。

原图预览与 iOS 使用同一画册底部面板：半透明遮罩、系统表面色、24px顶部圆角、完整图片预览标题、4:3整图、放大图片/适合窗口、不限次数 · 无惩罚、蓝色返回按钮。放大后可双向滚动，返回保留局面与原页面滚动；不使用微信原生黑底图片查看器。加载与重试在面板内显示。导入任意横竖图片时，隐藏处理画布的视图尺寸与像素尺寸同时更新，导入与4:3场景处理分别按目标尺寸导出，不能因画布视图裁切而丢失图像边缘。

## 微信组件兼容验收

普通小程序沿用 iOS 的页面尺寸和层级。微信 v2 默认按钮的184px宽度与自动外边距必须由页面按钮规则覆盖：列表行铺满内容区，导航和工具按钮按内容占宽，标题保留可用空间。验收须包括微信模拟器，浏览器适配检查应包含微信默认按钮规则。画布查询须绑定当前有效页面，并等待视图更新完成；加载失败或超时显示重试，不能无限保持加载状态。

拼片图集画布的视图尺寸须与像素尺寸一致，视图更新完成后再绘制与导出，避免微信按视图尺寸截取时放大裁切。12/24/48块均须包含全部完整拼片与凸出边缘。

拖动拼片须覆盖棋盘，不能被棋盘截断。微信容器用隐藏Canvas绘制棋盘，再把结果显示在普通图片视图中；棋盘、拖动预览和调整面板共享页面显示层，避免原生画布覆盖普通视图。棋盘上的预览与托盘区域都须验收；取消拖动须清除预览且保留已保存位置。异步绘制结果须防止退出或新绘制后旧结果覆盖当前画面。

棋盘画面采用两层图片缓冲，新画面加载完成后才切换可见层；落格和调整时保留旧画面，不能因图片解码暂时白屏。旧请求或退出后的加载事件不允许切换画面。

松手落格时，拖动预览按棋盘拼片的同一格子尺寸和图集边距立即贴合，去掉抓取阴影，保持到包含该次摆放的新棋盘图片加载完成；切换棋盘与移除预览须在同一次视图更新中完成，不能先消失再出现。再次抓取或取消、退出须撤销旧交接，旧加载回调不能清除新拖动的预览。取消棋盘拼片拖动须恢复原位置显示。

组件组合不得把棋盘、托盘、进度和工具全部包装成各自厚重卡片。PNG 插画、棋盘 mask、按钮、文字是不同资产层；变化时避免互相烘焙。

当前预览规则：准备页与拼图页可一键打开完整原图，不二次确认、不限次数、无惩罚。原生支持放大查看；返回后棋盘格子、随机托盘顺序、托盘与棋盘滚动位置保持。姓名与故事文本仍由完成后的揭晓页面展示。

## iOS 容器实现 v0.5

SwiftUI承载WKWebView共享玩法；默认手机视图移除展示侧栏、模拟状态栏和边框，安全区由原生容器提供。界面通过原生UIColor语义色跟随系统。固定本机HTTP来源与持久WKWebsiteDataStore保存图片和进度；不访问外部服务器。选图通过系统PHPicker/文件选择器，声音和触感桥接原生API，不依据格子对错触发。桌面设计演示使用?prototype=1。最低iOS16；首版iPhone竖屏。


## 微信小程序容器 v0.6

新增miniprogram/，保留iOS容器，显示名统一为拾光拼图册。小程序名称拾光拼图册，界面复用系统蓝、背景与文字语义、12/24/48块和同图预览。官方场景与拼片几何、中性落格规则通过web/shared.js共享。Canvas负责互补凹凸片与命中测试；点选片再点格与拖动等价，选中片可用上下左右按钮换格或取下。放大棋盘时独立浏览模式避免手势冲突。托盘四列多行滚动。微信原生导航与安全区负责胶囊和底部避让。

自建图片集以wx持久文件和元数据保存，支持批量导入、顺序与封面、裁切或完整保留、题目、试玩隔离与不可变图片版本；不上传。通过分包携带高清图，主包仅缩略图；预览、拼图和阅读使用同一母图。浅深色遵循系统，音效与触感为中性反馈。两端功能与内容同步维护，不含跨设备云同步。


## 2026-10-14 小程序完成与素材扩充

官方图库扩为24幅，共用场景、题目、出处和拼图规则。已有六关编号不变，新增18关顺序与用户图片对应。小程序名称“拾光拼图册”，尚未核验注册。iOS容器继续保留；两端数据各存本机，不提供跨设备同步。

微信托盘最少四行视窗，托盘使用紧凑四行视窗，提交按钮置于底部安全区，选中工具随内容排列；小屏可滚动查看。拼片被选中后，可点击任意棋盘格（包含已占格）放置，行为与拖动相同；拖动仍不校验答案。主题变化重新绘制画布。存档失败时保留草稿并阻止开始新局等依赖持久保存的操作。

24张场景分成12个本地资源分包，各包不超过2MiB，主包仅用缩略图。首开分包可能需要微信下载；资源缓存后可继续使用，不能承诺所有场景首次离线即可打开。
