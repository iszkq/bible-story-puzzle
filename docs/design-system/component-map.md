# 组件地图

| 组件 | 结构/尺寸 | 状态 | 使用与无障碍 |
|---|---|---|---|
| RootTab | 图标＋文字，原生 TabBar | 默认、选中 | 故事、我的故事集、收藏；SF Symbols 同一套，选中有文字语义 |
| NavigationHeader | 返回/关闭、标题、可选工具 | 默认、操作禁用 | 44pt 热区，不在拖拽区使用返回手势 |
| PrimaryButton | 17pt semibold，高度≥52pt，radius12 | 默认、按下、禁用、加载 | 每个决策区一个主要动作；加载保留标签防跳动 |
| SecondaryButton | 文字＋可选轮廓 | 默认、按下、禁用 | 放弃、重玩、故事入口；样式弱于主操作 |
| StoryCover | 4:3 画幅＋状态＋标题 | 未解锁、可玩、进行中、完成 | 官方未完成只用故事编号；首页与准备页显示完整原图，完成后显示名字 |
| ChapterRow | 编号、章节名、进度 | 当前、未来 | 首版一个可玩章节；未来章节不做空入口 |
| DifficultySelector | 12块/24块/48块、说明 | 默认、选中、不可用 | 首次12；难度改变不悄悄覆盖进行中的局 |
| ProgressLabel | 文案＋数值＋线条 | 0/N、部分、N/N | VoiceOver polite 播报；非必要不放百分比 |
| PuzzleBoard | 4:3网格画框＋格子ID＋可编辑拼片 | 空、部分、拖动、待提交、通过 | 12/24/48格，中性贴格；不判断正确目标；已占格交换/换回托盘；放大与方向键换格 |
| PieceTray | 四列多行拼片＋剩余数 | 默认、选中、抓起、已使用 | 热区≥44pt，滚动与抓取清楚区分，无编号；全部碎片置于可滚动托盘，保留滚动位置 |
| AnswerOption | 完整人物名＋选中标志 | 默认、选中、错误、正确 | 点击先选择再“确认答案”；不只用绿/红 |
| StoryReader | 插画、名字、正文、经文出处 | 已收藏、未收藏 | 可滚动、字号随系统；全文经文等译本确定后加入 |
| CollectionItem | 4:3封面＋人物名＋故事名 | 已收藏、可收藏、未发现 | 未发现只显示故事序号，不输出谜底到无障碍标签 |
| Sheet | 标题、说明、动作、关闭 | 提交结果、暂停、预览、重开确认 | 恢复棋盘状态；支持 Reduce Motion、VoiceOver 焦点 |
| EmptyErrorState | 明确状态、原因、恢复动作 | 空收藏、素材失败、存档损坏 | 文案讲当前可执行的动作，不只“出错了” |
| SettingsRow | 标签、解释、系统开关 | 开、关 | 整行可操作，朗读名称及值 |
| SubmitResult | 整体正确/仍有错误＋继续操作 | 未摆全、未通过、通过 | 仅提交时校验，不标错误块、不报告错误数量；未通过保持布局 |

组件组合不得把棋盘、托盘、进度和工具全部包装成各自厚重卡片。PNG 插画、棋盘 mask、按钮、文字是不同资产层；变化时避免互相烘焙。

当前预览规则：准备页与拼图页可一键打开完整原图，不二次确认、不限次数、无惩罚。原生支持放大查看；返回后棋盘格子、随机托盘顺序、托盘与棋盘滚动位置保持。姓名与故事文本仍由完成后的揭晓页面展示。

### 自建故事集组件

| 组件 | 结构/尺寸 | 状态 | 使用与无障碍 |
|---|---|---|---|
| SetRow | 4:3封面、名称、图片数、简介 | 加载、空、已保存 | 整行44pt以上，来源标签 |
| SetEditor | 名称、简介、图片序列、封面选择、保存 | 草稿、导入中、保存中、错误 | 编辑不覆盖原集；保存失败保留草稿 |
| ImageEditor | 4:3预览、裁切/完整保留、位置/缩放、文字、可选题目 | 处理、清晰度建议、无图、校验错误 | 滑块有标签与值，效果不拉伸，试拼12/24/48块 |
| ReorderRow | 缩略图、标题、上下按钮、拖动区域 | 可移动、边界禁用 | 桌面拖动和上下按钮等价；手机按钮可用 |
| DeleteConfirmation | 描述范围、删除、取消 | 故事集、图片 | 不误删旧版收藏和正在玩的快照 |

## iOS 容器实现 v0.5

SwiftUI承载WKWebView共享玩法；默认手机视图移除展示侧栏、模拟状态栏和边框，安全区由原生容器提供。界面通过原生UIColor语义色跟随系统。固定本机HTTP来源与持久WKWebsiteDataStore保存图片和进度；不访问外部服务器。选图通过系统PHPicker/文件选择器，声音和触感桥接原生API，不依据格子对错触发。桌面设计演示使用?prototype=1。最低iOS16；首版iPhone竖屏。
