# 拾光拼图册 · 小程序上传与发布

本次采用普通小程序。代码和图片随微信代码包发布，进度、收藏与个人图片保存在用户本机；不需要云开发、云托管或另外购买服务器。

1. 微信开发者工具打开本项目根目录（包含 `project.config.json` 和 `miniprogram/`），项目类型选“小程序”。当前工作区 AppID 已保留；从 GitHub 下载源码时填写自己的普通小程序 AppID，并用具备开发者权限的微信登录。
2. 点右上角“预览”，扫码打开手机体验版。模拟器测试记录见《小程序完整回归验收》，手机原生照片授权、系统静音和触感需以实际设备为准。
3. 点右上角“上传”，填写版本号（例如 `0.6.1`）与备注“同步 iOS 画册界面及预览面板，修复拼图渲染与图片导入，完成完整流程回归”。上传后产生开发版本。
4. 登录 [微信公众平台](https://mp.weixin.qq.com/)，进入对应 AppID 的小程序账号 → 版本管理 → 开发版本，可设为体验版，然后提交审核。填写后台要求的服务类目、简介、测试说明及隐私保护说明；如实描述拼图玩法和圣经人物故事内容，类目与资质以账号后台的要求为准。
5. 审核通过后，在版本管理中的审核版本点击“发布”，才会成为所有用户可访问的正式版。

个人图片仅在本机处理保存，没有上传或账号云同步。后台隐私接口声明应与实际图片选择及本机文件处理一致。后续更新仍走“开发者工具上传 → 后台审核 → 发布”。不用把 ZIP 上传到云服务器。

本次仅更新源码仓库和交付文件，没有代为上传、提交审核或发布微信版本。
