# 拾光拼图册 · 微信版本上传与发布

本工程使用本地资源分包与本机存档，不需要购买服务器，也不需要开启云开发或云托管。开发者工具“上传”把代码提交到微信平台；上传、审核、发布是三个独立步骤。

## 1. 导入正确版本

- 小游戏：导入 `minigame-project` 文件夹，或新版小游戏ZIP解压后包含 `game.json` 的文件夹。类型为小游戏，填写正式小游戏AppID。
- 普通小程序：导入仓库根目录，读取根 `project.config.json`，填写正式普通小程序AppID。

两套账号身份和项目类型需对应。仓库内 `touristappid` 仅供本地调试，不能用于正式上传。通过开发者工具填写自己的AppID，使用已加入该账号开发者名单的微信号登录。

## 2. 手机预览后上传

先点“预览”扫码，在手机检查24张图片分包加载、12/24/48块拖动与提交、人物题目、收藏、退出后恢复、照片导入和裁切。小游戏这次也应确认不会再出现找不到 `game.json` 的入口错误。

确认运行正常后点工具右上角“上传”：版本号可填 `0.6.0`，备注可填“统一拾光拼图册名称，新增24幅故事拼图，完善图片集与拼图交互”。上传完成即为开发版本，还没有向所有用户发布。

## 3. 后台提交审核

登录 https://mp.weixin.qq.com/ ，切换到与上传AppID对应的账号。在“版本管理”（具体菜单以该账号后台为准）找到开发版本，设为体验版并扫码测试，然后提交审核。根据后台要求填写类目、介绍、测试说明、隐私保护说明和相关资料。

小游戏上线所需的主体、游戏资质和适龄提示等，以账号后台提示及当前平台规则为准。作品中包含圣经人物、经文与宗教故事，应如实申报内容，并在平台确认适用类目和资质；只修改名称不会改变审核内容。普通小程序版同样需确认游戏玩法与内容是否符合所选类目的要求。

本工程的用户照片只保存在当前设备，不上传服务器；隐私说明需与实际照片选择、文件保存等接口一致。发布前检查微信后台的隐私接口声明与工具检测结果。

## 4. 审核通过后发布

在后台审核版本中点击“发布”，发布完成才是线上正式版。审核拒绝时按具体原因修改、重新上传与提交。后续更新同样走上传 → 体验 → 审核 → 发布，不需要自行把ZIP传到云服务器。

当前交付已做本地结构、编译和自动检查，尚未完成微信模拟器与手机运行验证，也未代替用户上传或发布微信版本。
