# 微信小游戏独立容器

小游戏入口为 `minigame-project/game.js`，使用游戏 Canvas 和触摸事件，不依赖 Page、WXML、DOM 或外层目录。iOS 与普通小程序保留。

沿用现有系统色、4:3 图片、24 幅故事、12/24/48 块、互补凹凸拼片和提交时整体校验。未完成的官方故事只显示编号。拼片可以拖放，或先选片再点格；占格交换规则由共享核心实现。放大时开启浏览模式拖动画板；取下与方向按钮用于精确调整。

小游戏采用 Canvas 绘制与iOS共享网页版相同的页面结构：欢迎画面、首页主图与“今天，拼一个故事”、篇章列表、准备、拼图、认人物、揭晓、收藏和故事集。复用字号、留白、图片圆角、无底板导航文字、52像素主按钮及轻量底部标签栏；禁止另做密集按钮仪表盘。

游戏原生键盘负责输入，常用触控热区至少44逻辑像素。顶部避让微信胶囊，底部避让安全区。棋盘保持页面全宽4:3，不为塞下控件缩成小画框。托盘四列、四行独立滚动，所有拼片可浏览，位置持久保存。小屏页面也能滚动；主提交按钮固定底部。已发现故事可以阅读与重玩；篇章列表按完成进度开启后续故事。方向微调只在主动打开调整面板时出现，不常驻挤占棋盘。

图片集支持本机批量导入、替换、裁切/完整保留、裁切位置和缩放、排序、封面、标题/正文/出处、可选三选一题目、试玩与草稿恢复。更改图像生成新文件和新版本；旧进度引用原版本。试玩退出及冷启动恢复原游戏。删除图片集保留历史版本。图片不上传。

24幅高清图分为12个资源分包，每包有独立game.js。主包只含缩略图、欢迎图和音效。分包第一次使用可能需要网络下载，后续由微信缓存管理。

用户选定名称“拾光拼图册”。各端显示名统一；本次没有查询该名称的微信注册状态。

Canvas 不提供 WXML 语义树，不能宣称通过读屏无障碍验收。实际微信模拟器、手机性能、照片权限和键盘兼容性仍需在开发者工具/真机检查。
