# 八张素材验收意见

日期：2026-10-13。审查对象：用户本次提供的六幅故事图、App图标和欢迎插画。没有更改原图，没有把图片接入原型；本次仅做评审与缩略网格检查。

## 总体结论

可以作为第一版素材进入拼图试玩。六幅故事图画风接近，故事主体与关键物件可辨，无文字与UI烘焙，均为4:3，符合成人向的内容方向。实际效果偏写实绘画，较最初水粉手绘建议更写实，可将这套作为新的画风参考。

尚不能据此宣布正式上线素材全部验收：还需要真实互补拼片的乱序试玩、手机亮度检查、原图局部细节复核和故事内容审阅。

## 尺寸与裁切检查

六幅故事图和欢迎图均为1448×1086，准确4:3；图标为1254×1254。没有达到规划的3200×2400母版目标，但353pt宽iPhone画面在3倍显示下约需1059px宽，这组尺寸足以开始手机原尺寸试玩。超大放大、iPad展示及后续精修空间有限；如果制作工具保留更高分辨率原图，优先用原图，不靠普通放大宣称达到高分辨率品质。

已制作六图353px宽、6×4网格对照。该检查只能判断小尺寸和区域辨识度，没有执行实际乱序凹凸片试玩。手机真实屏幕为2×/3×输出，353px图用于观察布局大小，不是最终导出标准。

图片2/3上方天空，图片4麦田，图片5暗岩壁，是24块试玩的重点区域。预览图可以随时查看，因此一定的相似区域可作为合理难度，不应因此把画面堆满无关装饰。

## 推荐处理顺序

1. 将摩西、挪亚、路得、以斯帖和欢迎图作为可用候选；摩西先做真实拼图。
2. 复核/修正大卫的投石索结构；局部提升但以理暗部可读性。
3. 故事图完整4:3用于棋盘与原图预览；预览、揭晓、收藏都从同一文件派生。
4. 生成互补mask并随机托盘顺序，分别试玩12、24和48块，测试随时预览返回时状态不变。
5. 判断是否需要高分辨率原图；没有确定问题不整套重新生成。
