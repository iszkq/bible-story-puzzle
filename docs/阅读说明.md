# 《拼见圣经》设计包 · v0.4

中文名暂定《拼见圣经》；英文名建议Bible Story Puzzle；建议GitHub仓库名bible-story-puzzle。当前仅本地原型，没有远程仓库链接。

成人向iOS游戏，使用系统浅/深色。原有10页加4个自建页面，网页已能实际导入图片并保存游玩。

1. [页面流程原型](../web/index.html?prototype=1)：刷新现有浏览器打开。新功能从底部“我的故事集”进入；首次可先点“浏览故事”。
2. [设计流程与iOS页面规划](设计流程与iOS页面规划.md)：所有页面、网格规则、恢复、素材与原生交接。
3. [自建故事集与网格玩法规划](自建故事集与网格玩法规划.md)：创建/编辑、图片处理、版本、状态、iOS实施与后续路线。
4. [素材需求与精美制作流程](素材需求与精美制作流程.md)：场景需求、精修、导入质量与加工步骤。
5. [中文生图提示词](中文生图提示词.md)：保留六张故事图、欢迎图与图标提示词。
6. [交互验收记录](交互验收记录.md)：实际浏览器检查与范围限制。

玩法：12/24/48块按难度划格，用户手动拖入格子，任何格子都自动贴合。放置时不判断对错；已占格互换，托盘新片入已占格则旧片退回托盘。提交才给整体结果，失败保持布局。准备页和预览显示完整原图；托盘四列多行，所有剩余片上下滚动查看。

自建流程：新建故事集→批量选图→编辑画面范围与故事→排序/选封面→试玩→保存。标题、故事、出处选填；题目默认关闭。图片可裁切4:3或等比完整保留，不拉伸。试玩返回/刷新恢复原先游戏；换图生成新版，旧游戏与收藏仍可用旧图。

运行时保持HTML、故事集.js和assets在同一目录。建议用本地服务器，并保持地址/端口一致；命令见[README](README.md)。图片保存在当前浏览器IndexedDB，游戏进度保存在localStorage，不进行网络上传。清除网站数据会移除内容；分享、同步和备份导出尚待后续。

八张初始素材由用户提供，assets/originals保留原文件，本次AI新增生成0张。六幅场景和欢迎图1448×1086可用于手机试玩，发布母版仍建议精修到3200×2400；详见[八张素材验收意见](八张素材验收意见.md)。

旧自由坐标局按所在格子迁移，不按答案修正；冲突片退回托盘。旧完成与收藏记录保留。重置演示进度只清游戏与收藏，不删除自建图库；删除故事集需另确认。

当前是网页交互原型，不是可安装iOS App。原生布局、PhotosPicker/HEIC、真机触控、VoiceOver、音效/触感和内容审阅仍待原生阶段。设计契约在docs/design-system，继续开发先读AGENTS.md。
