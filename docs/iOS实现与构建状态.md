# iOS 实现与构建状态 · v0.5

仓库地址：https://github.com/iszkq/bible-story-puzzle

应用显示名《拼见圣经》，英文名 Bible Story Puzzle，Bundle ID `com.iszkq.biblestorypuzzle`，最低 iOS 16.0；首版 iPhone 竖屏。工程采用 SwiftUI 容器和 WKWebView 共享游戏逻辑，并非所有页面重写为 SwiftUI。

## 已实现

- iOS 移动视图去掉设计展示侧栏、假状态栏、假 Home Indicator 和手机边框，由原生容器提供真实安全区。
- 六张官方故事图、欢迎图和图标离线内置。运行时约 5 MB，不打入高清原图和未使用局部裁切图；原素材留在仓库备查。
- 12＝4×3、24＝6×4、48＝8×6，所有格子中性吸附。手动拖动、占格交换／退回托盘、错误保留布局、主动提交、整体校验，成功进入题目／故事／收藏流程。
- 随时完整预览；放大棋盘有浏览模式；托盘四列四行可视窗口和纵向滚动。布局、托盘顺序、滚动、缩放与阶段持久保存。
- 我的故事集：批量图片、范围调整、完整保留、文字、可选题目、排序、封面、草稿、保存、编辑、删除、三档试玩和不可变图片版本。
- 系统 PHPicker／UIDocumentPicker 导入。原生 ImageIO 检查 20 MB／4000 万像素限制、修正方向并降采样至最长边 2560；有透明通道时用 PNG 保留透明，无透明时用 JPEG；随后进入共享裁切与版本管线。
- 固定本机地址 `127.0.0.1:18765` 仅提供 App 内置资源，WKWebsiteDataStore 持久保存本地图片资料库；不允许外部导航，没有网络图片上传。
- 原生 UIColor 语义色跟随系统浅深色。阅读文字、标题、题目和编辑输入支持系统文字大小。拿放反馈与格子答案无关；音效遵守静音，音效／触感开关独立生效。
- 试玩备份改为持久存储，退出页面或 WebView 重建时恢复之前正式游戏，试玩不写入成就和收藏。
- macOS 自动编译、ARM64 未签名 IPA 打包、包内资源和无签名验证、模拟器启动／选图入口 UI 测试、浏览器自动验证，以及失败时构建日志上传。

## 已验证与待验证

本机 Windows 上通过了 37 项自建故事集检查、21 项官方网格／裁切检查、67 项移动页面／桥接／恢复检查（共 125 项），以及工程对象引用、共享 scheme、plist、图标、准确离线资源拷贝和设计契约检查。浏览器检查使用 Edge／Chromium，不能代表 iOS WebKit 或真机性能。

当前机器没有 Xcode。GitHub CLI 的 iszkq 登录失效，Git 凭据管理器没有可用凭据，实际 push 未通过认证，因此尚未上传远程、未运行 macOS 编译、尚未生成 IPA。工程静态检查不等于 Swift 编译成功；最终编译／模拟器结果以 Actions 记录为准。

完成本机 `gh auth login` 后，推送 `main` 会自动启动两项 Actions。IPA 名称为 `BibleStoryPuzzle-unsigned.ipa`，位于 `BibleStoryPuzzle-unsigned-ipa` 构建产物中。它必须经过签名才能安装到普通 iPhone。

仍需 iPhone 实测：PHPicker／文件读取、系统大字、VoiceOver 网格移动、48 块拖动／滚动、长时间内存、强制终止／恢复，以及图片内容专家审阅。远程分享、云同步与公开社区未实现。
