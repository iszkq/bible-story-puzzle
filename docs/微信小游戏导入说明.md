# 拾光拼图册 · 微信小游戏导入

## 导入当前电脑上的项目

1. 打开微信开发者工具，选择小游戏项目的“导入”。
2. 项目目录选择 `C:\Users\Administrator\Desktop\pintu\minigame-project`。不要选择外层 `pintu`：外层配置对应此前的普通小程序。
3. 项目名称填写“拾光拼图册”。AppID填写你在微信公众平台登记的**小游戏 AppID**。普通小程序 AppID不能作为该项目的小游戏身份。
4. 当前配置使用 `touristappid` 作为本地开发占位；如果工具提供测试号/游客模式，可先用于本地调试。预览、上传与发布请使用自己的小游戏 AppID，并确认当前微信号有开发者权限。
5. 确认项目类型为“小游戏”，导入后点击“编译”。使用现成代码，不创建模板，不需要npm构建或云开发环境。
6. 进入模拟器验证：欢迎页 → 关卡准备 → 12/24/48块拼图 → 提交 → 认人物 → 故事与收藏；再检查“图片集”里的导入、编辑与试玩。照片权限、原生键盘及触感需在手机预览检查。

## 使用压缩包

新版“拾光拼图册-微信小游戏.zip”解压后，直接选择解压文件夹：`project.config.json`、`game.json`、`game.js` 在同一层，没有嵌套的 `minigame-project`。

旧包有一层 `minigame-project`。如果导入了旧包外层，需将外层配置的 `miniprogramRoot` 设为 `minigame-project/`，或重新导入内层目录。开发者工具使用 `miniprogramRoot` 指定代码根目录，小游戏同样适用；项目类型由 `compileType: game` 指定。此前写的 `minigameRoot` 已改正。

## 当前交付内容

界面按iOS现有画册设计适配微信安全区。包含24幅插画、人物题目和故事；12/24/48块互补凹凸拼片、中性吸附、占格交换、拖放/点放、放大浏览、不限次原图预览、整体提交校验、本机恢复与收藏。个人图片集支持批量导入、编辑替换、裁切/完整保留、排序/封面、可选题目、不可变图像版本和隔离试玩。

高清图按需加载本地资源分包，首次下载可能需要网络。用户照片复制到微信持久文件目录，不上传；所有存档保存在当前设备。小游戏与iOS各自保存数据。

已完成结构、资源包大小、JavaScript语法、本地Canvas模拟和四种手机尺寸交互检查。这些检查不代表已通过微信运行时、真机或发布审核。本次按用户要求先交付文件，未启用开发者工具服务端口；iOS应用显示名已同步，Windows无法进行Xcode构建。

名称“拾光拼图册”由用户选定，本次未查询微信注册状态。
